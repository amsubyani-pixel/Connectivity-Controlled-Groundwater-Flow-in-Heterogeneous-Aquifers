# Connectivity-Controlled-Groundwater-Flow-in-Heterogeneous-Aquifers
This notebook expands the original three-case connectivity experiment to seven controlled hydraulic-conductivity topologies.
Connectivity-Controlled Groundwater Flow in Heterogeneous Aquifers
Seven-Topology Numerical Laboratory
This Jupyter notebook provides a reproducible numerical framework for investigating how the spatial topology of hydraulic conductivity controls effective groundwater flow in heterogeneous porous media.
The central experiment holds the sampled hydraulic-conductivity values constant within each paired realization and rearranges those same values into seven contrasting spatial structures. This design separates the effect of the conductivity distribution from the effect of spatial connectivity and organization.
Research Question
Can heterogeneous aquifers with the same hydraulic-conductivity population exhibit substantially different effective groundwater-flow behavior solely because the spatial arrangement of conductivity differs?
The primary hydraulic responses evaluated are:
- Longitudinal effective hydraulic conductivity, Keff_x
- Transverse effective hydraulic conductivity, Keff_y
- Directional anisotropy, Keff_x / Keff_y
Additional diagnostics include discharge, flux localization, hydraulic-gradient localization, spanning connectivity, minimum-path resistance, variogram structure, topology effect size, and uncertainty reduction.
Seven Conductivity Topologies
The notebook compares seven controlled spatial configurations:
Case	Topology	Main Hydraulic Mechanism
A	Randomly dispersed	High-K extremes are locally scattered and long connected backbones are suppressed
B	Connected parallel channel	Continuous high-K pathway connects inlet and outlet
C	Connected transverse barrier	Continuous low-K band crosses the regional flow direction
D	Broken high-K channel	Preferential pathway is interrupted by localized bottlenecks
E	Branching network	Multiple connected high-K branches provide redundant flow pathways
F	Layered system	Strong longitudinal continuity and weak transverse connectivity generate anisotropy
G	Isotropic stochastic	Gaussian/lognormal reference field without imposed non-Gaussian topology


All seven cases are constructed from the same sampled log-conductivity values in each paired realization through rank-preserving spatial transformations.
Governing Equation
The model solves steady, saturated groundwater flow:
\[
\nabla \cdot [K(\mathbf{x}) \nabla h] = 0
\]
with Darcy flux:
\[
\mathbf{q} = -K(\mathbf{x}) \nabla h
\]
Effective conductivity is calculated from the integrated discharge under an imposed hydraulic-head difference. Directional simulations are performed to estimate both Keff_x and Keff_y.
Numerical Methods
The main groundwater-flow solver is a cell-centered finite-volume method (FVM) using harmonic averaging of face conductivities.
The notebook includes:
- Sparse matrix assembly
- Direct or conjugate-gradient linear solvers
- No-flow transverse boundaries
- Constant-head upstream/downstream boundaries
- Global mass-balance checking
- Homogeneous analytical benchmarking
- Independent P1 finite-element method (FEM) verification
- Grid-convergence analysis
These checks are included to distinguish physical topology effects from numerical artifacts.
Stochastic Conductivity Generation
A stationary Gaussian parent field is generated using padded spectral synthesis and transformed to a lognormal hydraulic-conductivity field.
Alternative topology fields are generated by assigning the same sampled log-conductivity values to new spatial locations using rank mapping.
This preserves the empirical one-point conductivity distribution exactly within each paired realization while intentionally changing spatial organization.
The notebook also computes directional semivariograms to document changes in second-order spatial structure.

Monte Carlo Experimental Design
The study uses a paired factorial Monte Carlo framework with three primary controls:
1. Conductivity topology
2. Log-conductivity variance, sigma_Y^2
3. Normalized structural scale, lambda/L
Within every parent realization, Cases A-G use the same conductivity sample. This paired design allows topology effects to be evaluated without confounding them with changes in the sampled conductivity distribution.
A fixed MASTER_SEED is used for reproducibility.

Interpretation
The numerical experiment is designed to test the proposition that identical one-point hydraulic-conductivity statistics do not uniquely determine effective groundwater-flow behavior.
The framework therefore emphasizes the distinction between:
- conductivity distribution,
- second-order spatial structure,
- topological connectivity,
- and dynamically expressed hydraulic connectivity.
Connected high-conductivity pathways, transverse low-conductivity barriers, bottlenecks, branching networks, layering, and unstructured fields are treated as distinct hydraulic mechanisms rather than as interchangeable representations of heterogeneity.
